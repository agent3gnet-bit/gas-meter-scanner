# Газовый счётчик - Распознавание показаний

Приложение для распознавания серийных номеров (из штрихкода) и 5-значных показаний газовых счётчиков.

## Возможности

- 📷 Захват изображений с веб-камеры
- 📁 Загрузка изображений из файлов (JPEG, PNG, BMP, TIFF)
- 📊 **Чтение штрихкода** — серийный номер из штрихкода
- 🔍 OCR распознавание 5-значных показаний
- 📊 Сопоставление серийного номера с лицевым счётом
- 💾 Экспорт в Excel (xlsx)
- 📋 История всех показаний
- ➕ Добавление новых серийников в справочник

## Использование

```cmd

```
Или клик по ярлыку **GasMeterReader** на рабочем столе.

### Справочник (`reference_db.xlsx`)
| Серийный_номер | Лицевой_счёт | Абонент | Адрес |
|---|---|---|---|
| 1234567890123 | 12345678 | Иванов И.И. | ул. Пример, 1 |

### Распознавание
1. Загрузите фото счётчика (штрихкод + показания)
2. Нажмите **"🔍 Распознать"**
3. Приложение прочитает штрихкод (SN) и 5 цифр показаний
4. Проверьте и нажмите **"💾 Сохранить в Excel"**
